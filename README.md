# SnowRunner: True 240Hz Physics Patch

A lightweight plugin for **SnowRunner** that unlocks the internal physics simulation tick rate from the default 60Hz to **240Hz**, delivering smoother suspension response, winch operation, and high-speed handling.

## Available Versions
* **Table Version:** Built specifically for the **Steam** version (direct memory offset).
* **Scan Version:** Uses dynamic AOB pattern scanning for universal compatibility across **Steam**, **Epic Games Store**, and **Microsoft Store** (experimental).

## How to Report Bugs & Crashes
If the plugin fails to inject, has no effect, or causes a game crash, please open a **[New Issue](../../issues/new)** and include:
1. **Game Platform:** (e.g., Steam, Epic Games, MS Store)
2. **Plugin Version Used:** (`Table` or `Scan`)
3. **Log / Crash Info:** Drag and drop your `.log` file or screenshot directly into the issue text box.
